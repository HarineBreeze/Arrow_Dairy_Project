# 阿尤日记 AyoDiray — 应用上架待办清单

> 核对时间：2026-11-27　｜　基线版本：v5.0.7+165　｜　包名：`com.Ayo.diary_app`
> 说明：本清单分「APP 内（代码/UI，可协助改造）」与「APP 外（主体资质/账号/提交，需本人办理）」两部分。

---

## 0. 先看清自己的合规画像（决定哪些不用做）

从 `android/app/src/main/AndroidManifest.xml` 与代码依赖核实到的现状：

| 维度 | 现状 | 对上架的影响 |
|---|---|---|
| 联网 | main manifest **无 INTERNET 权限**，纯离线单机 | 无服务器 → 不需要域名 ICP 备案、ICP 经营许可证、EDI |
| 账号 | 无登录、无账号体系 | 不需要「账号注销」入口（但要在隐私政策中明确说明） |
| 支付 | 灵感点数/兑换码/VIP 均为**本地虚拟权益**，无真实收款 | 通常不需要支付资质；需如实说明「不涉及真实货币交易」 |
| 第三方 SDK | 仅 path_provider / image_picker / file_picker / share_plus 等基础插件，无上报类 SDK | 隐私政策可声明「不收集个人信息、不接入第三方统计/广告 SDK」 |
| 权限 | 通知、精确闹钟、开机自启、震动、文件/图片读取（导入导出/分享） | **权限用途说明 + 按需动态申请**是审核重点 |
| 签名 | release 已接入与电脑端一致的 keystore，SHA256 已对齐 | 已就绪，无需改动 |
| 隐私政策 / 用户协议 / 备案号 | **App 内完全没有**（全量检索无匹配） | ⚠️ 当前最大缺口，商店必拒 |

**结论**：你的合规工作量集中在「资质文件 + App 内三件套（隐私政策/用户协议/备案号）+ 权限说明 + targetSdk 升级」，而不是支付/账号那套重资产流程。

## 1. APP 内环节（代码与 UI 层，可协助改造）

### 1.1 隐私政策（最高优先级，当前缺失）
- [ ] **首次启动弹窗**：展示《隐私政策》+《用户协议》，用户主动同意后才能进入；不同意可退出或仅浏览，不得强制。
- [ ] **离线可查看**：本 App 无网络，政策正文必须**内嵌在 App 里**（不能用网页链接），可在设置页/侧边栏常驻入口随时打开。
- [ ] **内容要如实**：写明「本应用为离线工具，不上传、不收集个人信息；图片/文件读取仅用于本地导入导出与分享；通知与闹钟仅用于你设置的到期提醒；无账号体系、无真实支付」。
- [ ] 商店后台通常还要填一个**可公开访问的 HTTPS 隐私政策链接**（App 内嵌之外），可用 GitHub Pages / Gitee Pages 托管一份。

### 1.2 用户协议（当前缺失）
- [ ] 与隐私政策成套，说明使用规则、虚拟权益（灵感点数/兑换码）性质、免责条款。
- [ ] 同样内嵌 + 首次启动一并同意。

### 1.3 APP 备案号展示（强制，当前缺失）
- [ ] 在设置页底部或「关于」中显示备案号文本，格式如 `X ICP备XXXXXXXX号-X`。
- [ ] 点击可跳转工信部备案查询（`https://beian.miit.gov.cn`）。
- [ ] 备案号必须与商店后台、开发者账号主体完全一致，否则直接驳回。

### 1.4 权限说明与按需申请（审核重点）
- [ ] **通知权限 POST_NOTIFICATIONS**：Android 13+ 须在用到提醒功能时**运行时动态申请**，弹窗前说明用途；被拒后日记/记账等基础功能仍可用。
- [ ] **精确闹钟 SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM**：Android 12+ 需引导用户到系统设置开启；代码里已有「无权限则退化为非精确闹钟」的兜底，符合最小必要，但要在隐私政策中披露。
- [ ] **开机自启 RECEIVE_BOOT_COMPLETED**：说明仅用于恢复你设置的到期提醒。
- [ ] **图片/文件读取**：说明仅用于本地导入导出与分享，不上传。
- [ ] 逐项自查是否存在「申请了但没用到」的权限——有多余就删。

### 1.5 名称与技术信息一致性
- [ ] 应用名「阿尤日记」、软著名、APP 备案名**三者一致**（不一致是高频驳回点）。
- [ ] 商店后台技术信息填写准确：包名 `com.Ayo.diary_app`、签名证书 **MD5 / SHA256**、versionCode `165` / versionName `5.0.7`。

### 1.6 目标 SDK 升级（技术债）
- [ ] 当前 `compileSdkVersion 33`、`targetSdkVersion` 跟随旧版 Flutter 默认值（约 33），已低于 2026 年主流商店准入线。
- [ ] 建议升级 **compileSdk / targetSdk 至 35 或 36**（Google Play 自 2026-08-31 起要求 API 36；国内商店普遍要求 ≥ 34）。
- [ ] 升级后真机回归 Android 14/15/16 行为变更：通知运行时权限、精确闹钟、前台服务类型、edge-to-edge 沉浸式、预测返回手势、大屏/折叠屏自适应。
- [ ] 同步升级过旧的 Flutter SDK（当前安装版本已 1600+ 天未更新），否则新版 targetSdk 可能无法配置。

### 1.7 质量自检（提审前）
- [ ] 冷启动无崩溃、无占位文案、无死按钮；核心流程（记账/日记/提醒/导入导出）全路径真机跑通。
- [ ] 截图与将要提交的构建包版本一致，不含「Beta」「即将推出」字样。

## 2. APP 外环节（主体资质 / 账号 / 提交，需本人办理）

### 2.1 主体材料
- [ ] **营业执照**（企业主体）或身份证（个人开发者）。注意：华为、应用宝等已**不接受个人新注册**，建议用企业主体。
- [ ] 执照在有效期内，经营范围与 App 功能相关，准备加盖公章的扫描件。

### 2.2 软件著作权（安卓商店硬性门槛）
- [ ] 办理《计算机软件著作权登记证书》，名称与 App 名一致（或提供 APP 电子版权证书 / 软件著作权认证证书，三选一）。
- [ ] 周期：普通 40-60 工作日，加急 30-40 工作日 → **最先启动**。
- [ ] 渠道：中国版权保护中心或代理。

### 2.3 APP 备案（法律强制，未备案不得上架）
- [ ] 通过接入商（阿里云 / 腾讯云 / 华为云）提交 APP 备案。
- [ ] 材料：主体证照、负责人核验、App 名称与功能说明、包名、签名 MD5。
- [ ] 周期：约 5-25 工作日（接入商初审 3-5 天 + 管局终审 2-20 天）。
- [ ] 备案号下来后**回填 1.3 的 App 内展示**；安卓/iOS 同名称只需备案一次。
- [ ] 纯离线 App 同样需要备案，无豁免。

### 2.4 公安备案（容易遗漏）
- [ ] 上线后 **30 日内**在「全国互联网安全管理服务平台」完成公安备案。

### 2.5 各应用商店开发者账号
- [ ] 逐个注册并完成认证：华为、小米、OPPO、vivo、应用宝、荣耀（部分需缴保证金）。
- [ ] **每个账号的主体必须与软著、备案主体一致**，否则驳回。

### 2.6 商店素材
- [ ] 应用图标（按各商店尺寸规范，已有 mdpi~xxxhdpi + 自适应图标可复用）。
- [ ] 截图 ≥ 4-5 张，真实对应当前版本，突出日记/物品/资产/隐私锁等核心界面。
- [ ] 应用描述、一句话简介、分类、关键词、版本更新说明。
- [ ] 年龄/内容分级问卷（本 App 无不适内容，如实填写即可）。

### 2.7 提审与跟进
- [ ] 逐店提交，预留 2 轮审核；跟踪驳回原因（高频：描述与实现不符、权限理由不足、备案号不一致、名称不一致）。
- [ ] 审核期间保持联系邮箱有人监控。

### 2.8 若同时上 iOS（可选）
- [ ] Apple 开发者账号（99 美元/年）。
- [ ] 隐私清单 `PrivacyInfo.xcprivacy` + App Store Connect 隐私卡片（本 App 无第三方 SDK，填写较简单）。
- [ ] 年龄分级、支持网址与邮箱。
- [ ] 国内发布同样需要 APP 备案；无真实数字商品则无需 IAP。

## 3. 优先级与时间线（倒推法）

| 阶段 | 事项 | 周期 | 谁来做 |
|---|---|---|---|
| **T-90 立刻启动** | 软著申请、确认营业执照经营范围 | 40-60 工作日 | 你 |
| **T-60 并行** | APP 备案、注册各商店开发者账号、准备隐私政策文本 | 5-25 工作日 | 你 + 可协助文本 |
| **T-30 收尾** | App 内隐私政策/用户协议/备案号/权限说明落地、targetSdk 升级 | 1-2 周 | 我可协助改代码 |
| **T-15 提审** | 商店素材、逐店提交 | 1-2 周 | 你 + 可协助素材 |
| **T 上线** | 上架、30 日内公安备案 | — | 你 |

**关键路径**：软著周期最长，必须最先启动；备案与 App 内改造可并行；命名一经确定不要再改。

## 4. 明确不需要做的（避免白花时间）

- ❌ ICP 经营许可证 / EDI（无联网经营、无第三方入驻）
- ❌ 支付牌照 / 微信支付宝商户（无真实收款）
- ❌ 网络文化经营许可证、视听许可证、游戏版号（非游戏/音视频/直播）
- ❌ 账号注销功能（无账号体系）
- ❌ 第三方 SDK 数据上报清单（无上报类 SDK，隐私政策据实声明即可）
- ❌ 公安联网备案以外的安全评估报告（除非个别商店额外要求）
