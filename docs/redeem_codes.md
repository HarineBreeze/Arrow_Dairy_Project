## 实现位置

- 码表与发放逻辑：`lib/services/reward_service.dart`
  - `pointsCodes`：限 1 次的积分码
  - `unlimitedPointsCodes`：不限次数的加分码（不写 `redeemedCodes`）
  - `unlimitedDeductCodes`：不限次数的扣分码（不写 `redeemedCodes`，最低 0）
  - `badgeCodes`：身份牌码
- 兑换记录字段：`UserProfile.redeemedCodes`（`lib/models/user_profile.dart`）
- 用户 ID / 注册日：`UserProfile.userId` / `registeredAt`，首次启动生成并固化

## 其它获取积分的途径

- 每日首次发布笔记：+20 积分（`RewardService.dailyWritePoints`）
- 积分商城消费：诞生日-身份牌 50 积分 / VIP日卡 200 积分
